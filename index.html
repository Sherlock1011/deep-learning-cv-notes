分章讲义

入门第 1 章：环境、Python 与 PyTorch 基本操作

学习目标：完成 Anaconda/Jupyter/PyTorch 环境，知道 tensor 是什么，能在 notebook 中运行代码、查看形状、做基础运算。

  • 环境优先级：Python 版本 → Jupyter Notebook → PyTorch → CUDA/GPU 检查。
  • 先学会张量的创建、索引、变形、广播、矩阵乘法，再进入网络层。
  • 这章不要陷入安装细节；能稳定运行一个 notebook 就够。

检查点：能写出一个张量，打印 shape，完成矩阵乘法，解释 CPU/GPU 张量为什么不能随意混用。

对应视频：土堆 PyTorch；李沐 d2l

入门第 2 章：数据管道与训练闭环

学习目标：把“数据 → 模型 → 损失 → 反向传播 → 优化 → 验证”这一条链路跑通。

  • 数据侧：Dataset、DataLoader、transforms、torchvision 数据集。
  • 监控侧：TensorBoard 记录 loss、图片、模型结构，帮助你观察训练过程。
  • 训练侧：认识 nn.Module、forward、损失函数、优化器、保存和读取模型。

检查点：能在 CIFAR-10 上训练一个小网络，保存模型，再用验证图片跑一次推理。

对应视频：土堆 PyTorch
原笔记： 103 104 105 106 107 108 115 116 118 119 121

基础第 3 章：深度学习数学与基础模型

学习目标：理解线性回归、Softmax 分类、多层感知机、自动求导和神经网络前向/反向传播。

  • 线性回归让你理解“模型、参数、损失、优化”的最小闭环。
  • Softmax 回归把回归问题拓展为分类问题，是后续图像分类的基础。
  • MLP 让你看到激活函数和隐藏层如何提供非线性表达能力。
  • 吴恩达课程适合补概念，李沐笔记适合补代码实现。

检查点：能不用高级封装写出线性回归训练循环，并能解释为什么分类任务常用交叉熵。

对应视频：李沐 d2l；吴恩达深度学习
原笔记： 206 207 208 301 302 303 304 305

基础第 4 章：优化、正则化与调参方法

学习目标：学会诊断训练问题：欠拟合、过拟合、梯度消失/爆炸、学习率不合适、初始化不稳。

  • 正则化主线：权重衰退、丢弃法、数据增强、早停。
  • 优化主线：SGD、Momentum、RMSProp、Adam、mini-batch。
  • 调参主线：先划分训练/验证/测试，再做误差分析，最后改模型或改数据。

检查点：看到训练集准确率高、验证集准确率低时，能提出至少三种处理手段，并说明优先级。

对应视频：李沐 d2l；吴恩达深度学习
原笔记： 209 210 211 212 314 315 316 323 324

CV 核心第 5 章：CNN 与经典视觉网络

学习目标：理解卷积、填充、步幅、池化、多通道、1x1 卷积，以及 LeNet/AlexNet/VGG/NiN/GoogLeNet/ResNet 的结构演进。

  • 从“局部连接 + 权重共享”理解卷积为什么适合图像。
  • 从 LeNet 到 ResNet，看网络为什么越来越深，以及残差连接解决了什么问题。
  • 这章要把输入输出尺寸算熟：卷积核、padding、stride、channel 如何改变张量形状。

检查点：给定一张 3x224x224 图片和卷积参数，能手算输出尺寸；能画出 ResNet block 的数据流。

对应视频：土堆 PyTorch；李沐 d2l；吴恩达 CNN

CV 项目第 6 章：CV 实战、检测、分割与迁移

学习目标：从图像分类走向更真实的视觉任务：迁移学习、数据增强、目标检测、语义分割、风格迁移。

  • 图像分类实战：CIFAR-10、狗品种识别，重点练数据处理、训练评估和提交思路。
  • 检测主线：边界框 → 锚框 → R-CNN/SSD/YOLO → SSD 实现。
  • 分割主线：转置卷积、FCN、语义分割数据集。
  • 迁移学习是小数据场景的关键能力：先用预训练骨干，再微调任务头。

检查点：能说清楚分类、检测、分割三类任务的标签形式和模型输出有什么不同。

对应视频：李沐 d2l；吴恩达 CNN

工程第 7 章：工程训练、GPU 与多卡

学习目标：把单机实验升级到更稳定的训练工程：GPU、日志、模型保存、评估、多卡、分布式训练。

  • 先学会单 GPU：设备迁移、显存观察、训练速度比较。
  • 再理解多 GPU：数据并行、梯度同步、批量大小与学习率关系。
  • 最后看分布式训练：知道概念即可，初学阶段不强求完整部署。

检查点：能把模型和数据都迁移到 GPU，并解释为什么只迁移模型或只迁移数据会报错。

对应视频：土堆 PyTorch；李沐 d2l
原笔记： 120 215 227 228 229 230 231

NLP第 8 章：序列模型、RNN、GRU、LSTM

学习目标：理解文本为什么要按序列建模，以及 RNN/GRU/LSTM 如何处理上下文依赖。

  • 先掌握文本预处理：分词、词表、序列截断/填充。
  • 再学语言模型：用前文预测下一个 token。
  • RNN 是基本循环结构，GRU/LSTM 解决长依赖和梯度问题。
  • seq2seq 是机器翻译、摘要等生成任务的经典框架。

检查点：能解释隐藏状态的作用，能说明为什么 LSTM 比普通 RNN 更适合长文本。

对应视频：李沐 d2l；吴恩达序列模型
原笔记： 246 247 248 249 250 251 252 256 257 342 343

NLP 进阶第 9 章：注意力、Transformer 与 BERT

学习目标：从 seq2seq 的瓶颈过渡到注意力机制，理解 Transformer 的自注意力、多头注意力、位置编码、预训练与微调。

  • 注意力的核心问题：当前输出应该重点看输入序列的哪些位置。
  • 自注意力让序列内部任意位置直接交互，Transformer 由此摆脱循环结构。
  • BERT 代表“预训练 + 下游微调”的范式，为后续大模型学习打基础。

检查点：能用自己的话解释 query/key/value，能区分 Encoder-only 的 BERT 和生成式模型的用途差异。

对应视频：李沐 d2l；吴恩达序列模型
原笔记： 258 259 260 261 262 263 264 265 344

Agent第 10 章：大模型 Agent、RAG 与 API

学习目标：把前面的深度学习背景迁移到应用层：理解 API 调用、向量数据库、RAG 检索增强、LangChain、多轮对话。

  • 先理解大模型调用：API key、prompt、系统提示、流式输出、温度参数。
  • 再理解 RAG：文档切分 → embedding → 向量库 → 相似度检索 → 拼接上下文 → 生成答案。
  • 最后看 LangChain：它主要帮你组织 prompt、检索器、链路和工具调用。

检查点：能画出一个简单 RAG 流程，并说明“向量数据库存的不是原始理解，而是 embedding 表示”。

使用建议

  • 每天节奏：30% 看视频，40% 跑 notebook，20% 自己复述，10% 整理错误。
  • 不要跳过代码：这份资料的价值在于 notebook 实操，只看视频会很快忘。
  • 每章都要有产出：哪怕只是一个尺寸计算表、一张流程图、一个小实验，也比“看完了”更可靠。
  • 遇到公式卡住：先会用、会调、会解释现象；第二轮再补严格推导。
  • 最终项目建议：选择一个图像分类/检测项目和一个 RAG 问答项目，分别作为 CV 与 Agent 的阶段成果。
